# [PRD] 개인용 스마트 투두(Todo) 관리 웹 애플리케이션

## 1. 프로젝트 개요 (Overview)
- **프로젝트 명**: Daily Task Tracker (개인용 할 일 관리 앱)
- **목적**: 매일 10~20개의 일상 및 업무 태스크를 브라우저에서 직관적으로 등록, 관리, 완료할 수 있는 고성능 경량 웹 애플리케이션
- **핵심 가치**: 빠른 접근성(No-install), 직관적인 진행 상황 가시화(Progress), 데이터 지속성 및 백업(Persistence/Backup), 모던 테마(Dark/Light), 순수 기술 기반의 높은 안정성(Vanilla JS)

---

## 2. 기능 요구사항 명세 (Functional Requirements)

### 2.1 핵심 할 일 CRUD 및 인터랙션
| 기능 ID | 기능명 | 상세 내용 |
| :--- | :--- | :--- |
| **FR-01** | **할 일 추가** | 텍스트 입력 후 등록 버튼 또는 `Enter` 키 입력 시 목록에 추가. 빈 문자열 방지 |
| **FR-02** | **할 일 목록 조회** | 추가된 순서대로 목록 표시. 완료 여부, 카테고리 태그, 중요도(⭐), 드래그 핸들 제공 |
| **FR-03** | **완료 토글** | 체크박스 클릭 시 완료/미완료 상태 전환, 완료 시 취소선 및 투명도 조절 |
| **FR-04** | **인라인 편집** | 수정 버튼 또는 텍스트 더블 클릭 시 인라인 입력창으로 즉시 전환 (`Enter` 저장, `ESC` 취소) |
| **FR-05** | **할 일 삭제** | 개별 삭제 버튼 클릭 시 목록에서 즉시 제거 |
| **FR-06** | **드래그 앤 드롭 순서 변경** | HTML5 Drag & Drop API를 활용하여 항목을 마우스로 끌어 원하는 우선순위로 재배치 |

### 2.2 중요도(⭐) 및 카테고리/검색 시스템
| 기능 ID | 기능명 | 상세 내용 |
| :--- | :--- | :--- |
| **FR-07** | **중요도(⭐) 지정** | 등록 시 또는 목록에서 별표 아이콘을 클릭하여 중요 할 일로 지정/해제 |
| **FR-08** | **카테고리 지정** | 등록 시 '업무(Work)', '개인(Personal)', '공부(Study)' 중 1개 선택 |
| **FR-09** | **실시간 키워드 검색** | 검색창에 키워드 입력 시 일치하는 할 일만 실시간 필터링 |
| **FR-10** | **다중 필터 탭** | 카테고리 탭(전체/업무/개인/공부)과 상태 탭(모두/진행 중/완료/⭐ 중요) 교차 필터링 |
| **FR-19** | **키워드 기반 자동 카테고리 분류** | 입력 텍스트 내 키워드를 실시간 분석하여 적절한 카테고리(업무/개인/공부)를 자동 감지/추천 및 시각 피드백 제공 (On/Off 토글 지원) |

### 2.3 대시보드 및 동기부여/루틴 관리
| 기능 ID | 기능명 | 상세 내용 |
| :--- | :--- | :--- |
| **FR-11** | **진행률 및 통계** | (완료 수 / 전체 수) * 100% 실시간 게이지 바 및 전체/진행중/완료/중요 카운트 표시 |
| **FR-12** | **100% 달성 축하 폭죽** | 모든 할 일 완료(100%) 시 내장 Canvas Confetti 폭죽 효과와 "🎉 올클리어!" 뱃지 표시 |
| **FR-13** | **연속 달성 스트릭(Streak)** | 목표 달성 시 연속 달성일수(🔥 N일 연속) 카운터 자동 갱신 |
| **FR-14** | **새 하루 시작 (루틴)** | "새 하루 시작" 클릭 시 완료 항목을 아카이브에 저장하고 미완료 항목만 남겨 새로운 하루 시작 |

### 2.4 테마 및 데이터 지속성/백업
| 기능 ID | 기능명 | 상세 내용 |
| :--- | :--- | :--- |
| **FR-15** | **다크 모드(Dark Mode)** | 라이트/다크 모드 원클릭 토글 지원 및 사용자 설정 로컬스토리지 유지 |
| **FR-16** | **로컬스토리지 자동 저장** | 모든 상태 변경 즉시 브라우저 `localStorage`에 자동 동기화 |
| **FR-17** | **JSON 데이터 백업** | 현재 할 일과 스트릭 데이터를 `daily_task_backup_YYYY-MM-DD.json`으로 내보내기(Export) |
| **FR-18** | **JSON 데이터 복원** | 백업된 JSON 파일을 불러와 앱 데이터를 즉시 복원(Import) |

## 3. 기술 사양 (Technical Specifications)

- **언어 및 환경**: 순수 HTML5, CSS3, ES6+ Vanilla JavaScript (외부 라이브러리 및 외부 CDN 의존성 0%)
- **데이터 모델 스키마**:
  ```json
  [
    {
      "id": "task_1720000000000_abc",
      "text": "Antigravity 아키텍처 문서 작성",
      "category": "work", // "work" | "personal" | "study"
      "completed": false,
      "starred": true,
      "createdAt": "2026-09-22T14:20:00.000Z"
    }
  ]
  ```
