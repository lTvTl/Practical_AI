# Daily Task Tracker (개인용 할 일 관리 앱)

매일 10~20개의 할 일을 스마트하게 관리할 수 있는 모던 웹 애플리케이션입니다. 외부 프레임워크나 복잡한 빌드 도구 없이 **순수 HTML5, CSS3, Vanilla JavaScript**만으로 구현되었습니다.

---

## 🚀 실행 방법

별도의 서버 설치나 빌드 과정 없이 즉시 실행할 수 있습니다:
1. `study_02/index.html` 파일을 브라우저(Chrome, Edge 등)로 더블 클릭하여 엽니다.

---

## ✨ 추가 구현된 주요 기능

### 1. 🌓 테마 (다크 모드 / 라이트 모드)
- 우측 상단 해/달 아이콘 버튼 클릭으로 라이트/다크 테마 즉시 전환
- 시스템 환경(OS 테마) 자동 감지 및 선택한 테마 영구 유지

### 2. ⭐ 중요도 별표 (Priority Star)
- 입력창 및 각 할 일 항목의 별표(⭐)를 눌러 중요 태스크 지정
- 통계 대시보드에 중요 항목 수 실시간 표시
- 필터 탭에서 `⭐ 중요` 선택 시 중요한 일만 모아서 집중 관리 가능

### 3. 🔍 실시간 키워드 검색
- 상단 검색창에 단어를 입력하면 일치하는 할 일이 즉시 필터링
- 10~20개의 많은 할 일 중 원하는 태스크를 1초 만에 검색

### 4. 🔀 인터랙션: 드래그 앤 드롭 (Drag & Drop)
- 마우스로 항목 좌측의 드래그 핸들(`⋮⋮`)이나 항목 자체를 끌어서 원하는 우선순위대로 자유롭게 순서 재배치

### 5. 🎉 동기부여: 100% 달성 축하 효과 & 스트릭(Streak)
- 오늘의 모든 할 일을 완료(100%)하면 화려한 **Canvas Confetti 폭죽 효과**와 `🎉 올클리어!` 뱃지 등장
- 매일 목표를 달성하면 `🔥 N일 연속` 스트릭 카운터가 누적되어 동기부여 제공

### 6. 📅 루틴 관리: 새로운 하루 시작 (아카이브)
- `☀️ 새 하루 시작` 버튼을 누르면 완료된 항목들을 별도 아카이브에 영구 저장하고, 오늘 목록에는 미완료 항목만 남겨 상쾌하게 하루를 시작

### 7. 💾 데이터 백업 및 복원 (JSON Export & Import)
- **[📥 백업 저장]**: 현재 작성된 모든 할 일과 스트릭 데이터를 `daily_task_backup_YYYY-MM-DD.json` 파일로 다운로드
- **[📤 백업 복원]**: 저장해둔 백업 JSON 파일을 불러와 다른 브라우저나 PC에서도 그대로 복원

### 8. ⚡ 키워드 기반 자동 카테고리 분류 (신규)
- 할 일 입력창에 단어를 입력하면 텍스트 내 키워드를 실시간으로 분석하여 적합한 카테고리(`💼 업무`, `🌿 개인`, `📚 공부`)를 자동으로 추천/선택
  - **업무(Work)**: 회의, 보고서, 프로젝트, 기획, 개발, 배포, PR, 스프린트, jira, review 등
  - **개인(Personal)**: 운동, 헬스, 산책, 장보기, 병원, 약, 요리, 청소, 식사, 분리수거 등
  - **공부(Study)**: 공부, 책, 독서, 강의, 인강, 복습, 시험, 자격증, 문제풀이, 알고리즘 등
- **실시간 피드백 뱃지**: 감지된 키워드와 추천 카테고리를 직관적인 안내 배너와 펄스 애니메이션으로 즉시 표시
- **사용자 제어 (On/Off 토글)**: 카테고리 상단의 `⚡ 키워드 자동 분류` 스위치로 기능을 자유롭게 활성화/비활성화 가능 (설정 브라우저 영구 저장)
- **수동 선택 존중**: 사용자가 직접 카테고리 라디오를 클릭하면 해당 선택을 최우선으로 존중
- **원클릭 카테고리 변경**: 등록된 할 일 항목의 카테고리 뱃지를 클릭하면 `업무 ➔ 개인 ➔ 공부` 순으로 즉시 카테고리 전환 가능
