# 정보처리기사 기출 퀴즈 게임 (CBT Quiz App)

국가기술자격 **정보처리기사 필기 기출문제**를 가볍고 재미있게 풀며 실전 감각을 익히고 합격을 준비할 수 있는 반응형 웹 퀴즈 게임 애플리케이션입니다.  
외부 라이브러리나 복잡한 빌드 과정 없이 **순수 HTML5, CSS3, Vanilla JavaScript (Zero-Dependency)**로 제작되어 높은 안정성과 즉각적인 실행을 지원합니다.

---

## 🚀 실행 방법

별도의 웹 서버 구동이나 패키지 설치 없이 브라우저에서 즉시 실행할 수 있습니다:
1. `study_03` 폴더의 [`index.html`](./index.html) 파일을 웹 브라우저(Chrome, Edge, Safari 등)에서 더블 클릭하여 실행합니다.

---

## ✨ 주요 기능 및 특징

### 1. 📚 5개 전 과목 60문항 기출문제 은행 & 10문제 무작위 출제
* 최신 국가기술자격 **정보처리기사 필기 5개 과목**의 실제 기출문제 60문항이 엄선되어 수록되어 있습니다:
  * **1과목 소프트웨어 설계**: GoF 디자인 패턴, 객체지향 5대 원칙(SOLID), UML 다이어그램, 애자일 선언문, 아키텍처 패턴 등
  * **2과목 소프트웨어 개발**: 결합도와 응집도, 화이트박스/블랙박스 테스트, 리팩토링, 통합 테스트(드라이버/스텁), 알고리즘 복잡도 등
  * **3과목 데이터베이스 구축**: 정규화(1NF~BCNF), 트랜잭션 ACID 특성, 순수 관계연산자, 인덱스, 뷰, NoSQL 등
  * **4과목 프로그래밍 언어 활용**: C/Java/Python 문법 및 실행 결과, OSI 7계층, TCP/UDP, 서브넷 마스킹, 프로세스 상태/스케줄링 등
  * **5과목 정보시스템 구축관리**: 소프트웨어 비용산정(COCOMO), 웹 보안 취약점(SQL Injection, CSRF), 대칭/비대칭 암호 알고리즘 등
* 라운드 시작 시 문제 은행에서 **10개의 문제를 중복 없이 무작위(Fisher-Yates 셔플)로 추출**하여 매번 새로운 퀴즈 세트를 제공합니다.

### 2. ⚡ 즉각적인 피드백 & 💡 핵심 해설 영역
* 보기를 클릭하는 즉시 정답 여부를 판정합니다:
  * **정답 시**: 선택한 보기 버튼 초록색 강조 + '🎉 정답입니다!' 피드백 + 맑은 딩동 사운드 출력
  * **오답 시**: 선택한 보기 버튼 빨간색 강조 + 실제 정답 버튼 초록색 표시 + '❌ 오답입니다!' 피드백 + 버저음 출력
* 정답 판정 후 문제 하단에 **핵심 해설 박스**가 부드럽게 펼쳐져 정답의 근거와 핵심 개념을 바로 복습할 수 있습니다.
* 자동으로 넘어가지 않고 유저가 **[다음 문제 ➔]** 버튼을 직접 클릭해야 진행되므로 충분한 학습 시간을 확보할 수 있습니다.

### 3. ⏱️ 정밀 타이머 & 🏆 클린 순위표 (Leaderboard)
* 퀴즈 시작부터 완료까지 소요된 시간을 초 단위로 실시간 측정합니다.
* **더미 데이터 없는 순수 사용자 랭킹**:
  * 사전 등록된 가짜 기록 없이, 오직 실제 사용자가 풀고 등록한 기록만 깔끔하게 누적·관리됩니다.
  * 점수가 등록되지 않은 초기 상태에서는 친절한 안내 문구가 표시됩니다.
* **순위 결정 알고리즘**:
  1. **점수(맞춘 개수 / 10)** 가 높은 순 (내림차순)
  2. 동점일 경우 **총 소요 시간**이 짧은 순 (오름차순)
* **[기록 초기화]** 버튼을 통해 언제든지 랭킹 기록을 리셋할 수 있습니다.

### 4. 🏅 가상 합격 판정 & 축하 애니메이션
* 정보처리기사 필기 합격 기준인 **60점(6문제 이상 정답)** 달성 시 가상 합격 메달(🏅)과 함께 브라우저 내장 Canvas Confetti 폭죽 효과 및 승리 팡파레가 연출됩니다.
* 6문제 미만일 경우 오답 복습을 권장하는 친절한 피드백과 함께 원클릭 재도전 기능을 제공합니다.

### 5. ⌨️ 키보드 단축키 지원 (생산성 인터랙션)
* **[1], [2], [3], [4]**: 1~4번 보기 즉시 선택
* **[Space]** 또는 **[Enter]**: 다음 문제로 넘어가기 / 최종 결과 확인 / 닉네임 등록
* **[ESC]**: 순위표 모달 닫기

### 6. 🌓 다크 / 라이트 모드 & 🔊 Web Audio API 효과음
* 우측 상단 테마 버튼을 통해 다크 모드와 라이트 모드를 자유롭게 전환할 수 있으며, 사용자 설정은 브라우저에 영구 저장됩니다.
* 외부 오디오 음원 파일(mp3 등) 다운로드 없이 브라우저 내장 **Web Audio API**로 실시간 주파수를 합성하여 네트워크 오류나 파일 유실 없이 맑은 효과음을 제공합니다. (사운드 On/Off 토글 지원)

## 🛠️ 기술 사양 (Technical Specifications)

* **언어 및 환경**: HTML5, CSS3, ES6+ Vanilla JavaScript
* **데이터 저장소**: 브라우저 `localStorage` (무설치, 영구 데이터 보존)
* **사운드 엔진**: HTML5 Web Audio API (합성 톤 제너레이터)
* **그래픽 효과**: HTML5 2D Canvas (Confetti 파티클 렌더링)
* **외부 의존성**: **0% (Zero-Dependency)**
