# 📝 정보처리기사 기출 퀴즈 게임 PRD (제품 요구사항 정의서)

## 1. 프로젝트 개요
**정보처리기사 기출 퀴즈 게임**은 수험생 및 예비 개발자들이 정보처리기사 자격증 필기 기출문제를 게임처럼 가볍고 재미있게 풀 수 있도록 돕는 웹/모바일 퀴즈 애플리케이션입니다. 즉각적인 피드백과 심도 있는 해설을 제공하여 학습 효과를 극대화하고, 순위 시스템을 통해 반복 학습과 경쟁 심리를 유발하는 것을 목표로 합니다.

## 2. 핵심 게임 규칙
1. **문제 유형:** 모든 문제는 4지선다형(객관식 4보기)으로 출제됩니다.
2. **출제 범위:** 국가기술자격 '정보처리기사' 필기시험 기출문제(소프트웨어 설계, 소프트웨어 개발, 데이터베이스 구축, 프로그래밍 언어 활용, 정보시스템 구축관리)를 기반으로 구성됩니다.
3. **게임 단위:** 1회 플레이(1 라운드) 시 총 **10문제**가 무작위로 출제됩니다.
4. **즉각적 피드백:** 유저가 보기를 선택하면 즉시 정답/오답 여부를 화면에 표시하고, 정답에 대한 명확한 **해설**을 제공합니다.
5. **결과 및 순위:** 10문제를 모두 풀면 '최종 맞은 개수(점수)'를 보여주며, 유저의 이름을 입력받아 **순위표(Leaderboard)**에 기록합니다.

---

## 3. 기능 요구사항 (Functional Requirements)

### 3.1. 문제 은행 시스템
* **데이터베이스:** 정보처리기사 필기 기출문제를 50~100개 이상 사전에 구축해 둡니다. (문제, 보기 1~4, 정답 번호, 과목명, 상세 해설 포함)
* **랜덤 출제 로직:** 게임 시작 시 문제 은행에서 10개의 문제를 중복 없이 무작위로 추출하여 퀴즈 셋을 구성합니다.

### 3.2. 인게임 퀴즈 로직
* **화면 표시:** 현재 문제 번호 (예: 3/10), 과목명(예: 소프트웨어 설계), 문제 내용, 4개의 보기 버튼을 화면에 표시합니다.
* **정답 판정:** 유저가 보기를 클릭하는 즉시 클릭한 보기와 정답 번호를 대조합니다.
* **피드백 연출:** 
  * **정답 시:** 선택한 버튼이 초록색으로 변하며 '정답입니다!' 문구와 효과음 출력.
  * **오답 시:** 선택한 버튼이 빨간색으로 변하고, 실제 정답 버튼이 초록색으로 강조되며 '오답입니다!' 문구와 효과음 출력.
* **해설 제공:** 정답 판정 직후, 문제 하단에 준비된 **해설 영역**이 펼쳐지며 설명이 노출됩니다.
* **다음 문제 이동:** 해설을 읽은 후 유저가 [다음 문제] 버튼을 클릭해야 다음 퀴즈로 넘어갑니다. (자동으로 넘어가지 않아 충분히 학습할 시간을 제공)

### 3.3. 결과 및 랭킹 시스템
* **결과 산출:** 10문제 중 맞춘 개수를 계산하여 최종 점수(예: 8/10, 80점)를 보여줍니다.
* **사용자 등록:** 결과 화면에서 유저의 닉네임을 입력받는 폼을 제공합니다.
* **순위 보드(Leaderboard):** 
  * 점수(맞춘 개수)가 높은 순으로 정렬합니다.
  * 동점일 경우, 문제 10개를 푸는 데 걸린 '총 소요 시간'이 짧은 순으로 상위에 랭크합니다. (이를 위해 백그라운드 타이머 기능 필요)

## 4. UI/UX 및 화면 구성

1. **시작 화면 (Intro)**
   * 게임 타이틀 및 로고 ("정보처리기사 기출 퀴즈 게임")
   * "기출문제 10개 풀기" 시작 버튼
   * 상위 TOP 5 랭킹 리스트 미리보기

2. **게임 화면 (In-game)**
   * 상단: 진행도 프로그레스 바 (Progress Bar, 1/10 ~ 10/10) 및 백그라운드 타이머
   * 중앙: 기출문제 텍스트 (길 경우 스크롤 지원) 및 과목 태그
   * 하단: 4개의 보기 버튼 (터치/클릭 영역을 넓게 확보)
   * 하단 팝업: 정답/오답 결과 및 상세 해설 (선택 후 노출), [다음 문제] 버튼

3. **결과 화면 (Result)**
   * 최종 맞힌 개수 표시 (예: "당신의 점수는 10점 만점에 8점!")
   * 합격/불합격 여부 가상 판정 (6개 이상 맞히면 가상 합격 메달 부여 등)
   * 닉네임 입력란 및 [순위 등록] 버튼
   * [순위표 보기] 버튼 및 [다시 풀기] 버튼
